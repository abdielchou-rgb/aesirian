# Æsirian 营销素材

## 一句话定位

> **Æsirian：一个理解叙事的 AI 写作伙伴。它在你需要时给你建议，不需要时安静陪伴。**

## 卖点 3 条

1. **世界级叙事认知**：ToM 心智引擎追踪角色信念、166 道门禁审计、29 个方法论注册表——每条建议都标注"来自英雄之旅第 3 阶段"
2. **一键开始，零学习成本**：一句话灵感 → 完整章节；Ctrl+Enter 续写；所有核心操作 ≤ 2 步
3. **你的数据你的电脑**：本地 SQLite 存储 + 离线桌面应用，AI 用你的 Key，不绑架内容

## 场景

| 用户 | 痛点 | Æsirian 解法 |
|------|------|-------------|
| 网文新手 | 不知道怎么开始 | 一句话灵感 → AI 生成草稿 + 实时建议 |
| 连载作者 | 长篇一致性难维护 | ToM 追踪信念 + 跨章冲突自动检测 |
| 严肃创作者 | 风格难统一 | 风格指纹雷达 + 市场对标 + 去 AI 味 |

## 演示脚本（60 秒）

1. 打开灵感视图，输入"一个修复罪忆水晶的匠人发现了军方的秘密"
2. 点创建项目 → 载入第 1 章
3. Ctrl+Enter 让 AI 续写一段
4. 点提交章节 → 展示门禁摘要 + 跨章一致性
5. 切心智网格 → 点角色看信念 → 反转一条信念看张力变化
6. 切大纲 → 展示递归生成 + 方法论徽章
