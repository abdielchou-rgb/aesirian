## 5. 问题三：哪些错误类型 167 门禁完全没覆盖？（→ 新增候选）

以下 12 例植入缺陷**零净命中**——门禁把缺陷文本当「正常」放过：

| 错误类型 | 样本 | 说明 |
|---|---|---|
| 时间线矛盾 | S1-01 / S1-11 | 「修了十一年→二十一年」、时长同一句摇摆，无门禁响应 |
| 身份/对话者错位 | S1-02 | 角色台词互换、开价者错位 |
| 空间矛盾 | S1-03 | 同一场景楼层 A-3 / B-7 混用 |
| 事实/设定矛盾 | S1-04 | 协议编号前后不一致 |
| 称谓漂移 | S3-08 | 主角名陈默→林默，全文替换后无感知 |
| 重复信息 | S1-05 | 后段整句复述前段设定 |
| 情感直给+过度解释 | S1-06 | 情绪全说破 + 长篇心理解释（TPE-01 只查高频词，未覆盖解释段） |
| 逻辑断裂 | S1-10 | 明确拒绝后立刻照做、无动机转变 |
| 视角漂移 | S1-14 | 限知视角下写出他人内心 |
| 章末平收 | S1-09 | 强悬念铺垫被平收 |
| 意象重复 | S2-04 | 同一章内同意象 3 次无新信息 |

**根因**：一致性矛盾（SVT/IIT/DDT/CLM 等门禁）的入参依赖跨章事实/事件字段，纯章节文本下 pipeline 未推导 → 门禁缺参即跳过/宽松通过。

**已落地（P0-3）**：`core/csn_consistency.py` 中文数词归一化 + 数值事实扫描 + 跨章数值矛盾比对，经 `orchestrator.check_cross_chapter_consistency` 输出 `csn_numeric_contradiction`（BLOCK）——覆盖时间/年龄类矛盾（S1-01/S1-11 型）。本报告单章 run_full 不含此路径。

**仍为新增候选（对 V1.2 有价值）**：
1. 同章内称谓漂移/空间/设定矛盾门禁（S1-03/S1-04/S3-08 型——CSN 现走跨章，同段漂移需文本内检测）；
2. 重复信息门禁：n-gram/实体三元组同章去重检测（S1-05/S2-04）；
3. 视角门禁：第三人称限知视角下出现非 POV 角色内心词库（恐惧/决定/其实他心里）触发 WARN（S1-14）；
4. 动机门禁：拒绝→行动的反转需 1 个中间动机句（S1-10），可由规则或 LLM judge 提供。
