# Æsirian 用户指南

> 一个理解叙事的 AI 写作伙伴——在你需要时给你建议，不需要时安静陪伴。

## 快速开始

### 安装

**桌面版（Windows）**：
1. 从 Releases 下载桌面安装包（或按仓库 README「快速开始」从源码运行）
2. 首次启动自动拉起后端引擎（SQLite 本地存储，数据不离开你的电脑）

**浏览器版**：
```bash
cd <aesirian-repo-root>
python -X utf8 -m uvicorn bridge.api_server:app --host 127.0.0.1 --port 8765
# 打开 http://127.0.0.1:8765/dashboard.html
```

### 三步开始写作

1. **一句话灵感** → 顶部输入框输入想法，点「创建项目」（或直接点「✨ AI 生成」）
2. **写作** → 在编辑器里输入，随时按 `Ctrl+Enter` 让 AI 续写
3. **提交审计** → 点「提交章节」，查看 166 道门禁 + 跨章一致性 + 质量检测结果

## 功能指南

### ✍ 写作

| 操作 | 效果 |
|------|------|
| 输入文字 | 每 2 秒自动保存草稿到本地（不丢失） |
| `Ctrl+Enter` | AI 续写——基于上下文多变体择优生成 |
| 点击建议 | 建议文本插入光标位置 |
| ✨ AI 生成 | 从灵感生成整章草稿 |
| 载入第1章 | 载入内置示例《罪忆》 |

### ◇ 心智网格（ToM 可视化）

- 力导向布局，可拖拽节点
- **点击角色** → 右侧显示信念面板（信念值/置信度/目标/秘密数）
- 反转/添加信念 → 系统实时重算戏剧张力
- 橙色徽标 = 信念数，红点 = 秘密数

### ⊞ 审计

- **新手模式**：通过/警告/拦截三张摘要卡 + 重点提示
- **专家模式**：166 道门禁全量表格，可按警告/拦截过滤
- ⛓ 跨章一致性：事实矛盾/身份突变/信念冲突自动检测

### ◐ 风格

- 六维雷达图（虚词/词汇/句长/标点/对话/感官）
- 感官通道分布（视/听/触/嗅/味）
- 对话/叙述/独白占比
- ⺆ 风格市场：发布你的风格 → 浏览/应用他人风格（30% 混合）

### ⧉ 推演 / ✧ 发散

- **推演**："如果主角发现配角在撒谎…" → 克隆项目状态，生成 3 条分支，不污染主线
- **发散**：输入 2-8 个碎片画面 → 生成 5 条世界线（类型×结构×5 拍大纲+开头段）

### ☰ 大纲

- 一句话前提 → 递归生成幕→章大纲（4 模板：三幕/英雄之旅/救猫咪/故事圈）
- 每章自动标注：⚡GOAT 电荷 / ◇Dramatica 视角 / ⛓MICE 线程 / ▲高潮位 / 📖方法论
- MICE LIFO 违规自动验证

### ◍ Wiki

- 角色/地点/物品/事件 CRUD
- ⚡ 从章节自动收获（实体提取自动入谱）
- 支持手动添加与删除

### ☰ 章节 / 项目

- 章节列表：章次/标题/字数/评分，可查看/删除
- 项目切换器：多项目自由切换
- 📤 导出 Markdown / EPUB

## 高级能力

### 方法论标注

每条建议都标注来源——"来自 Campbell 英雄之旅"、"来自 ToM 张力检测"。点击 📖 徽章查看出处。

### AI 质量保障

AI 生成经过：
1. 多层上下文组装（项目设定+角色档案+最近章节+未闭合线索+用户输入）
2. 3 变体生成 + 温度扰动
3. 质量评分（字数+去AI味+门禁+风格一致性）
4. ≥80 分达标，否则吸收反馈再生成

### 去 AI 味 5 大检测

| 检测 | 来源 | 检查什么 |
|------|------|---------|
| AI 痕迹 4 规则 | InkOS | 段落均匀/模糊词/公式过渡/列表结构 |
| 现实效应 | Barthes | 抽象 vs 具体细节比例 |
| 控制幻觉 | Storr | 视角跳变/无回报/缺细节 |
| 微张力 | Maass | 段落级"微微拉紧" |
| Show Don't Tell | 经典技法 | 情绪"告诉" vs 身体信号"展示" |

## 常见问题

**数据存在哪？** 全部本地 SQLite（仓库根目录 `aesirian.db`），不联网上传。

**AI 需要什么 Key？** 设置任一环境变量即可：`DEEPSEEK_API_KEY` / `OPENAI_API_KEY` / `ZHIPU_API_KEY` / `ANTHROPIC_API_KEY`；或 `OLLAMA_HOST` 用本地模型。

**建议为什么没出来？** LLM 不可用时自动降级为规则建议（ToM 张力/冷却矩阵/读者模型），永远可用。

**重启后数据还在吗？** 在。所有项目/章节/信念持久化到 SQLite。
