# Lisa Cron 神经叙事：Wired for Story

## 核心论点

大脑用感官细节构建情感，没有情感卷入就没有阅读。

## 关键神经科学发现

### 1. 镜像神经元系统
- 读者看到角色做某件事时，大脑中负责执行该动作的区域被激活
- 不是说"她感到悲伤"，而是写"她的手指反复摩挲茶杯边缘，目光落在窗外某一处"——读者的大脑会自动填充情感
- 这解释了"展示vs告诉"的神经科学基础

### 2. 大脑的生存本能
- 故事不是娱乐，是大脑训练生存技能的方式
- 读者自动寻找故事中的"对我有用的信息"——社会规则、威胁信号、机会窗口
- 没有"生存相关性"的信息被自动过滤

### 3. 预期偏差
- 大脑不断预测下一步
- 当预测被验证→满足感（爽点）
- 当预测被打破→好奇心（鸿沟）
- 太容易被预测=无聊，太难预测=困惑

### 4. 共情机制
- 读者不关心角色本身——读者关心角色的目标
- 只有了解了角色的"为什么"，读者才会共情
- 共情的触发点：角色的欲望和障碍之间的张力

## 操作规则

### 规则1：每个关键情感转折点用感官细节

**不要写：**
```
她感到很紧张。
```

**写：**
```
她的指尖在膝盖上反复攥紧、松开，掌心全是汗。
```

### 规则2：不解释角色的情感

**不要写：**
```
他愤怒极了。
```

**写：**
```
他的指节泛白，茶杯在手中微微颤抖。
```

### 规则3：先让读者关心，再让角色遭遇

读者需要先知道角色的欲望（他想要什么？为什么？），然后她才会关心角色是否得到。

如果角色在读者还不知道他想要什么的时候就遭遇了不幸→读者无感。

### 规则4：一个场景只传达一种情感转变

每个场景的核心：角色的情感状态从A变成B。

- 一个场景展示多种情感变化→读者脑子处理不了
- 不变化=这个场景没有存在的必要
