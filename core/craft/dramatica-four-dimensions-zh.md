# Dramatica 故事四维

## 概述

Dramatica（Melanie Anne Phillips & Chris Huntley）将故事视为一个"四维数学模型"，每个维度代表故事系统的一个层面。

## 四维结构

### 1. 主情节（Overall Story）
- 所有角色共同参与的客观外部冲突
- 所有角色都知道的"公共问题"
- 通过客观视角观察

### 2. 次情节（Main Character）
- 主角的个人困境
- 主角独有的内部问题
- 主角的视角

### 3. 主题（Theme/Relationship）
- 主角和"影响角色"之间的价值观冲突
- 通过对比展现故事主题
- 两个角色代表两种相反的价值观

### 4. 角色弧线（Obstacle Character）
- 与主角形成镜像或对立
- 推动主角面对自身缺陷
- 最终"谁改变了谁"决定故事性质

## 关键概念

### 故事telling vs storymind
- Storymind = 一个完整的思维系统
- 每个维度是这个系统的一个功能模块

### 四维的动态关系
- 维度之间必须相互影响
- 任意一个维度的变化都会对其他三个产生连锁反应
- 缺少任何一个维度 = 故事系统不完整

### 价值观转换
- 每个维度涉及一个核心价值观
- 故事结束时，至少有两个维度的价值观发生转换

## 应用规则

1. 一个完整的故事必须包含全部四个维度
2. 每个维度必须有一个清晰的价值观转变
3. 维度之间必须有因果关系（不是四个独立的故事）
4. 主角的次情节变化必须影响主情节的发展
5. 主题维度的价值观冲突必须在高潮场景中得到"回答"
