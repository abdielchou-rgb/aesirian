# 中国网文大师技法

## 断章

### 6种大师级断章位置
1. **问题提出后**：主角或反面角色提出一个关键问题后，断章
2. **答案揭晓前**：一个关键信息将要揭晓的前一刻
3. **角色做决定后**：角色做出了一个重大决定，读者必须知道后果
4. **行动开始前**：计划制定后，执行开始前
5. **反转发生时**：意外的转折点
6. **新线索出现后**：一个新的关键线索出现

### 断章技巧
- 断章不只是"在悬念处切断"——是在读者阅读曲线**刚过峰值**的时候切断
- 最佳位置：读者看完当前事件**松了一口气但立刻被下个悬念勾住**的瞬间
- 前1000字必须有1-2个微悬念，前3000字必须有至少1个主要悬念

## 注水比

### 网文"注水"的三种合法方式
1. **环境描写注水**：用环境描写增加代入感（不推进情节但强化沉浸）
2. **内心独白注水**：角色的思考过程——展示角色的人格，制造共情
3. **对话注水**：角色间的互动，可以同时展示关系和推进小范围信息

### 注水比参考
- 正文/注水比 = 3:7 ~ 4:6（网文正常范围）
- 付费章节前不得注水（前3章注水比不得高于40%）
- 关键情节节点不得注水

## 勾子散布

### 勾子类型
1. **信息钩**：读者想知道某个信息
2. **关系钩**：读者想知道两个角色的关系走向
3. **事件钩**：读者想知道事件的发展
4. **身份钩**：读者想知道角色的真实身份
5. **世界观钩**：读者想知道世界观的规则

### 散布规则
- 每千字至少1个微型钩
- 每3000字至少1个中型钩
- 每10000字至少1个大型钩（构建全书的悬念）
- 每章结尾必须有钩子（断章）
- 没有新钩子前，不要解旧钩子

## 升级节奏板

### 典型升级节奏
- 第1-5章：筑基/觉醒 → 首次小突破
- 第5-15章：首次战斗/冲突 → 初步成功
- 第15-30章：新层次/新对手 → 心态变化
- 第30-50章：中期格局变化 → 主角地位上升
- 第50-80章：高端冲突 → 主力层次
- 第80-100章：最终突破 → 终极格局

### 节奏检查点
- 每10章：有没有连续3章以上的"平淡区"？
- 每30章：主角有没有获得实质性的地位或能力提升？
- 每50章：格局有没有扩张到新的层次？
- 全书70%处：是否还有足够的空间给高潮前的铺垫？

## 付费章节检测

### 付费章节前必须完成
1. 至少一个完整的小事件（开篇—发展—高潮—收束）
2. 主角的核心欲望已经建立
3. 至少有2-3个角色让读者记住了名字
4. 至少有一个"爽点"（第一次打脸/第一次突破/第一次获得认可）
5. 世界观已经完成基础展示（不要求完整，但不能让读者迷惑）

### 付费章节的"黄金1000字"
- 付费章节的前1000字必须有实质进展
- 不能在前500字内出现大段心理描写/环境描写
- 付费章节的标题必须包含读者"必须知道"的信息

## 标题创作

### 网文标题公式
- 核心矛盾 + 特殊设定 + 身份反差
- 最好能在20字内让读者知道：主角是谁、主要冲突、类型暗示

## 全勤与连载管理

### 日更建议
- 保底：2000字/天
- 正常：3000-4000字/天
- 爆发：6000+字/天（周限2-3次）

### 连载防崩
- 提前5章储备大纲
- 每10章做一次"角色一致性自检"
- 避免超过3章无爽点
- 感情线：甜虐比保持3:1左右
