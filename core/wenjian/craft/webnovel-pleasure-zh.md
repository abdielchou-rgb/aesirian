# 爽点工程知识库

## 六大爽点类型

### 1. 打脸爽

**公式：** 被轻视 → 主角展现实力 → 众人震惊/后悔

**强度分级：**
- L1 轻度：口头反驳，让对方哑口无言
- L2 中度：小范围展现实力，震惊在场几人
- L3 重度：大范围打脸，震惊全场，连锁反应
- L4 极致：铺垫数章后的终极打脸，颠覆所有人认知

**节奏：** 每个大篇章至少包含 1 个 L3 以上打脸。

### 2. 升级爽

**公式：** 遇到瓶颈 → 突破 → 获得新能力 → 展示新能力

**节奏：**
- 修仙文：每 5-8 章一个小境界突破，每 15-20 章一个大境界突破
- 玄幻文：每 3-5 章一个小升级，每 10-15 章一个跨越式升级
- 都市文：每 5-10 章一次能力成长

**铁律：** 每次升级后必须在 2 章内展示新能力，否则读者感觉不到变强。

### 3. 奇遇爽

**公式：** 意外发现 → 获得机缘 → 实力跃升

**类型：** 捡宝、获得传承、遇到高人指点、发现秘境

**节奏：** 每个大篇章（约 20 章）至少 1 次奇遇。奇遇后需要 2-3 章消化成果。

### 4. 逆袭爽

**公式：** 绝境 → 反击 → 翻盘

**强度：** 逆袭的反差越大越爽。
- 从被所有人看不起到碾压全场
- 从绝境中找到一线生机到反杀

**节奏：** 逆袭前需要足够的铺垫（3-10 章压抑），压抑越久翻盘越爽。

### 5. 情感爽

**公式：** 误会/冲突 → 化解 → 关系升温

**类型：** 友情信任重建、爱情升温、师徒情谊、家族团聚

**节奏：** 情感爽不宜频繁使用，每 30 章 1-2 次即可。情感线的铺垫可以很长（50+ 章）。

### 6. 装逼爽

**公式：** 低调入场 → 不经意展现实力 → 众人惊叹

**关键：** 必须是"不经意"的展现。故意炫耀不是装逼。装逼的最佳状态是"主角没想装，但客观上装了"。

## 节奏控制

### 压抑与释放

```
压抑（蓄势） → 释放（爽点）
   3:1       →    1
```

每 3 章压抑需要 1 章释放。连续压抑不超过 3 章。

### 爽点密度

- 最低要求：每章至少 1 个微型爽点
- 正常节奏：每章 1-2 个微型 + 每 3 章 1 个中型
- 高潮章节：每章 2-3 个中型 + 1 个大型

### 大篇章节奏

```
压抑期（5-8章）→ 小高潮（1章）→ 过渡（2-3章）→ 蓄势（3-5章）→ 大高潮（1-2章）
```
