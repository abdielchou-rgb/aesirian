# 文鉴方法论 V2

## 一、总纲：文鉴的评价哲学

文鉴不判断一个故事"好不好看"——这不仅不可量化，也不该由算法决定。文鉴判断的是：**一个故事在多大程度上遵从了人类叙事史上被反复验证的有效原理。**

这背后是一个经验假设：好故事之所以"好"，不是玄学，而是它在某些量化维度上中了靶。文鉴的工作就是从7大理论源流中提取这些维度，将它们编织成145道可计算的门禁。

### V1 → V2 的升级

**V1（novel-os 50门禁）：** 基于 McKee《故事》的核心概念——场景价值观翻转、鸿沟密度、三层冲突、触点工程。聚焦"做对了什么"。

**V2（文鉴 145门禁）：** 在 McKee 基础上纳入6个新理论源流，覆盖"为什么有效"的深层因果：
- 人物弧光的伤疤与揭示（Truby）
- 读者大脑的生存本能（Lisa Cron）
- 故事结构的数学对应（Dramatica）
- 节拍精确性（好莱坞编剧技法）
- 网文留存率工程（十章法则 + 爽点工学）
- 语言质量的 MRU 与 POV（写作工艺技法）

## 二、七大理论源流

### 源流 1：麦基场景原理（McKee, "Story"）

**核心命题：** 故事的本质是"价值观的改变"。每个场景必须发生从一种价值到相反的不可逆翻转。

**提取维度：**
| 编号 | 概念 | 量化方式 |
|------|------|---------|
| M01 | 场景价值观翻转 | 入口价值 != 出口价值（关键词检测） |
| M02 | 鸿沟（Gap） | 角色预期结果与实际结果之间的差异（转折词密度） |
| M03 | 三层冲突 | 内心冲突 / 人际冲突 / 外部对抗的层次存在 |
| M04 | 激励事件 | 故事前25%打破主角生活平衡的不可逆事件 |
| M05 | 双重欲望 | 自觉欲望（外在）与不自觉需求（内在）的张力 |

**对应门禁组：** SVT(4道), GDA(4道), CLM(3道), IIT(3道), DDT(4道)

### 源流 2：特鲁比对手机（Truby, "The Anatomy of Story"）

**核心命题：** 角色不由"他是谁"定义，而由"和谁有什么关系"定义。故事是道德论战的舞台。

**提取维度：**
| 编号 | 概念 | 量化方式 |
|------|------|---------|
| T01 | 角色伤疤 | 每个角色是否有明确的过去伤痛（关键词 + 上下文） |
| T02 | 欲望冲突 | 自觉欲望与不自觉需求是否相反方向 |
| T03 | 弱点代价 | 主角的弱点是否导致了真实的失败 |
| T04 | 对手网深度 | 角色之间的多对多关系数量 / 角色总数 |
| T05 | 道德论战 | 主角是否面对过"正确但困难"与"错误但容易"的选择 |

**对应门禁组：** ARC(9道), CRN(5+1道), TRB(1道)

### 源流 3：德玛提卡四维结构（Dramatica）

**核心命题：** 好故事在4个域中同时运作。故事的核心冲突来自主角的"自我欺骗"。

**提取维度：**
| 编号 | 概念 | 量化方式 |
|------|------|---------|
| D01 | 四域激活 | 外部行动/内部心智/社会关系/抽象理念的关键词覆盖 |
| D02 | 逻辑一致性 | 问题陈述 → 解决方式之间的因果链完整性 |
| D03 | 问题-解决对应 | 问题是否在终幕被"解决"而不是被遗忘 |

**对应门禁组：** DRM(2道)

### 源流 4：丽莎·克朗神经科学（Lisa Cron, "Wired for Story"）

**核心命题：** 阅读不是感性的，是大脑的生存本能模拟。读者需要赌注、共情和预期偏差。

**提取维度：**
| 编号 | 概念 | 量化方式 |
|------|------|---------|
| L01 | 赌注存在 | 每场景是否有"角色会失去什么"的明确信号 |
| L02 | 困境普遍性 | 主角困境的"大众共鸣度"（关键词匹配通用人类困境） |
| L03 | 预期偏差 | "没想到但合理"的转折密度（GDA 的增强版，加因果必然性） |
| L04 | 共情触发 | 主角的内心体验是否被外部化呈现（而不只是内心独白） |
| L05 | 生存威胁 | 是否存在"不可挽回"的后果作为最高赌注 |

**对应门禁组：** NEU(3道)

### 源流 5：好莱坞节拍表（Save the Cat / 救猫咪）

**核心命题：** 经数百部成功电影验证的节拍位置精确到百分比。偏离太多 = 观众不适。

**提取维度：**
| 编号 | 概念 | 量化方式 |
|------|------|---------|
| H01 | 中点转折 | 45%-55%处从"反应"转为"进攻" |
| H02 | 一无所有 | 70%-80%处的最低谷 |
| H03 | 主题证明 | 终幕是否有第一幕的镜像事件 |
| H04 | B故事整合 | B故事与主线在3个以上节点交叉 |
| H05 | 邪恶力量揭示 | 表面反派背后的力量是否有节奏地揭示 |

**对应门禁组：** IIT-04, IIT-05, STR-07, DLG-07, RVI-06, SCB-*

### 源流 6：网文生存法则

**核心命题：** 网文读者的留存不是靠"故事好看"，是靠前10章的功能完整性 + 爽点节奏 + 断章工程。

**提取维度：**
| 编号 | 概念 | 量化方式 |
|------|------|---------|
| W01 | 黄金三章 | 前三章是否各自完成了不可缺失的功能 |
| W02 | 十章法则 | 前10章的功能完整性检查（每章一个强制功能） |
| W03 | 爽点密度 | 打脸/升级/奇遇/逆袭/情感/装逼的发生频率 |
| W04 | 断章工程 | 章末300字的钩子类型、强度、散布均匀性 |
| W05 | 注水比 | 相邻段落的信息重叠度检测 |
| W06 | 升级节奏 | 不同体裁的升级间隔标准（minor/medium/major） |
| W07 | 压抑释放比 | 蓄势章数与释放章数的比例 |
| W08 | 付费章质检 | 上架章节（30-40章）的质量是否明显下降 |

**对应门禁组：** G3(7道), PLE(7道), BRK(4+2道), QLT(5+1道), G10(10道), WNM(1道)

### 源流 7：写作工艺技术

**核心命题：** 脱离了适当的叙事工艺，再好的故事也无法被读者感知。

**提取维度：**
| 编号 | 概念 | 量化方式 |
|------|------|---------|
| C01 | MRU反应链 | Motivation-Reaction Unit 的完整性 |
| C02 | POV纪律 | 视角一致性——同一段内不应出现多视角 |
| C03 | 副词检查 | 副词密度（"地"结尾词 + 冗余修饰） |
| C04 | 被动语态 | "被"字句密度 |
| C05 | 赘词检测 | "基本上/实际上/非常/真的/有点/某种"的密度 |
| C06 | 对话质量 | 功能的推动力、潜台词、角色声音的独特性 |
| C07 | 场景/续篇结构 | 场景（目标→冲突→灾难）与续篇（反应→困境→决策）的交替 |
| C08 | 悬念管理 | 紧张度升级曲线、悬念密度、峰前释放、多重悬念 |
| C09 | 微观节奏 | 句子长度变异、段落内情绪对比、不可预测性 |

**对应门禁组：** LANG(5道), DLG(6道), SPN(4道), SCQ(5道), MTS(2道), TPE(3道)

## 四、分析层次与触发条件

文鉴的分析不是平铺的——它根据**故事进度**和**分析深度**分层激活门禁：

### Layer 0：单章快速扫描（零 API Key，< 1秒）
**激活门禁：** SVT-01, SVT-02, GDA-01/02/04, TPE-01/02, PRP-02, PLE-01, MTS-01/02, BRK-01/02/03/04, DLG-01/02/03/04/05/06, LANG-01/02/03/04/05, SPN-01/02/03/04, QLT-01/02/03/04/05, NFR-01/02/03/04/05
**触发条件：** 任何时候

### Layer 1：前10章黄金期检测
**激活门禁：** G3-01~07, G10-01~10
**触发条件：** chapter_index <= 10

### Layer 2：整书结构检测（需要至少5章积累）
**激活门禁：** SVT-03/04, IIT-01/02/03/04/05, DDT-01/02/03/04, CLM-01/02/03, RVI-01/02/03/04/05/06, ARC-01~09, STR-01~07, CRN-01~06, PLE-02/03/04/05/06/07, SCQ-01~05, ROE-01~06
**触发条件：** total_chapters >= 5

### Layer 3：大师层深度分析（需要语义提取或LLM辅助）
**激活门禁：** DRM-01/02, HOL-01, NEU-01/02/03, TRB-01, WNM-01, 救猫咪节拍表
**触发条件：** StoryGraph 提取完成

| 鸿沟密度下限 | 1.0 | 0.5 | 1.0 | 1.0 | 1.0 | 0.5 | 1.0 |

## 六、评价结果的四层输出

文鉴对一段文本的输出不是简单的 pass/fail，而是四层嵌套报告：

### 层1：整体判定
```
✅ PASS  — 无阻断，警告 < 5
⚠️ WARN  — 有警告但无阻断
❌ FAIL  — 有阻断门禁
```

### 层2：维度得分（0-100）
```
故事骨骼（结构）：85/100
故事肌肉（场景与鸿沟）：72/100
故事神经（人物与情感）：68/100
故事血液（读者卷入与爽点）：90/100
故事皮肤（文笔与风格）：78/100
故事系统（连贯性与世界观）：60/100
```

### 层3：门禁明细
每道门禁输出：gate_id / name / 结果 / 严重度 / 消息 / 细节数据

### 层4：修订路线图
对每个失败门禁，输出：
- 修订优先级（阻断 > 警告）
- 修订难度（低/中/高）
- 修订方向（具体建议文本）
- 参考示例（before/after 改写对照）
